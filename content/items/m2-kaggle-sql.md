## Tentang kursus ini

Kaggle Learn: Intro to SQL adalah kursus singkat gratis dengan latihan di notebook Kaggle. Datanya adalah dataset publik BigQuery, jadi kursus ini sekaligus mengenalkan cara kerja BigQuery yang akan Anda pakai untuk proyek theLook.

## Yang dikerjakan

- Masuk ke Kaggle dengan akun Google pribadi.
- Kerjakan **semua pelajaran beserta latihannya**, berurutan. Setiap pelajaran punya halaman materi (tutorial) dan notebook latihan (exercise).
- Topiknya mengulang dan memperdalam bacaan minggu ini: `SELECT`, `FROM`, `WHERE`, `GROUP BY`, `HAVING`, `ORDER BY`, `AS`, `WITH`, dan menggabungkan tabel.

## Yang perlu diketahui sebelum mulai

- **Ada sedikit kode Python di notebook.** Kaggle memakai Python untuk mengirim query ke BigQuery dan menampilkan hasilnya. Anda tidak perlu memahami bagian Python itu sekarang. Fokus pada teks query SQL di dalam tanda kutip. Python dipelajari di minggu 5.
- **Jalankan sel dari atas ke bawah.** Sel latihan bergantung pada sel persiapan di atasnya. Kalau muncul galat "not defined", jalankan ulang sel-sel di atasnya.
- **Ada pemeriksa jawaban otomatis.** Setiap latihan punya baris yang memeriksa jawaban (misalnya `q_1.check()`). Petunjuk (`hint`) dan solusi (`solution`) juga tersedia; pakai seperlunya dengan aturan yang sama seperti di SQLBolt.

> [!tip] Bandingkan dengan BigQuery langsung
> Setelah satu latihan berhasil, salin query-nya ke editor BigQuery Anda sendiri dan jalankan di sana, dengan nama tabel lengkap seperti di notebook. Ini latihan memakai BigQuery di luar Kaggle, persis seperti saat proyek nanti.

> [!warning] Perhatikan besar data
> Beberapa dataset publik sangat besar. Di notebook Kaggle, kuota ditanggung Kaggle, tetapi di BigQuery sandbox Anda sendiri kuotanya 1 TB per bulan. Sebelum menjalankan query di BigQuery, lihat perkiraan data yang akan diproses di kanan atas editor, dan sebut kolom yang dibutuhkan saja, bukan `SELECT *`.
