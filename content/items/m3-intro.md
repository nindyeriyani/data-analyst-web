## Kenapa Python

SQL sangat baik untuk mengambil dan meringkas data di database. Python dengan pustaka **pandas** melengkapinya untuk tiga hal:

- **Membersihkan data yang berantakan** dari file CSV atau Excel, misalnya teks yang perlu dipecah, tanggal campur aduk, atau nilai yang harus diperbaiki satu per satu dengan aturan.
- **Mengulang pekerjaan yang sama** setiap minggu atau bulan cukup dengan menjalankan ulang notebook.
- **Membuat grafik dan laporan** dalam satu dokumen yang berisi kode, hasil, dan penjelasan.

Semua dikerjakan di **Google Colab**, notebook Python di browser yang sudah Anda coba di minggu 1.

## Dua minggu ke depan

## Data latihan

Contoh pandas memakai data toko buku yang sama dengan modul SQL: 36 pesanan, Juli–September 2026. Anda sudah mengunduhnya sebagai CSV di pengantar modul SQL. Kalau file itu hilang, buka lagi item "Pengantar SQL untuk analisis", salin datanya ke Google Sheets, lalu unduh sebagai CSV dengan nama `penjualan_buku.csv`.

Karena datanya sama, Anda bisa membandingkan setiap hasil pandas dengan hasil SQL minggu lalu. Kalau angkanya sama, kode Anda benar.

> [!tip] Satu notebook per topik
> Buat notebook terpisah untuk setiap bacaan, misalnya `03-pandas-dasar.ipynb`, `03-pembersihan.ipynb`. Notebook yang pendek dan fokus lebih mudah dibaca ulang, dan nanti bisa dipilih yang terbaik untuk portofolio.

> [!warning] Data instansi tetap di kantor
> Latihan di Colab memakai data latihan, data publik, atau data tiruan. Colab menyimpan file di Google Drive dan server Google, jadi data internal tempat magang tidak boleh diunggah ke sana.
